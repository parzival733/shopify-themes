# Atelier Universal Shopify theme

Shopify OS 2.0 theme foundation. Customizable sections, product pages, collections, filters, predictive product search, AJAX cart drawer, checkout, FAQ, blog, contact and App Blocks.

## Test

Run `shopify theme check` and `shopify theme dev --store YOUR-STORE.myshopify.com` after connecting a development store. Confirm all real checkout and catalog flows before publication.

## Important

This foundation has not passed a live-store test, a performance audit, or WCAG 2.2 AA audit. It is not certified as production-ready. Configure Shopify Customer Privacy consent banner and regional preferences, legal policies, Search & Discovery filters, and reviews via a compatible Theme App Extension. Products with more than 250 variants need an option-value based progressive variant picker before launch. Gift card and pickup availability templates are not included in this first release.
