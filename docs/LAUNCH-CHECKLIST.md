# Launch checklist (merchant + developer)

- [ ] Connect a Shopify development store and run `shopify theme check`.
- [ ] Test product variants including 250+, stock, quantity rules and combined listings.
- [ ] Test selling plan allocations, subscriptions and payment buttons.
- [ ] Test physical, digital, gift-card and tax-included products.
- [ ] Test Shopify Markets: multiple locales, currencies, domains and localized paths.
- [ ] Configure Search & Discovery filters and recommendations.
- [ ] Add genuine product reviews through an app block and configure privacy/consent from Shopify Admin.
- [ ] Configure legal pages and footer navigation: terms, privacy, shipping, returns and imprint.
- [ ] Verify Shopify Customer Privacy opt-in/opt-out, scripts installed by apps and consent withdrawal.
- [ ] Test keyboard, screen reader, focus trapping, contrast, reduced motion and forms against WCAG 2.2 AA.
- [ ] Test Lighthouse LCP, INP and CLS across home/product/collection/mobile on a production-like store.
- [ ] Confirm mobile drawer, international checkout, Shop Pay, taxes and shipping rates on actual orders.
- [ ] Replace all placeholders with merchant content; never invent testimonials or discounts.

Passing the checklist and live audits is required before describing this implementation as production ready.
